# GAME VAULT 1.3 / LIBRARY AUDIT

## 更新
1. まず旧アプリの「設定・バックアップ」→ JSONを書き出す。現行データは削除しない。
2. GitHub `game-vault` のリポジトリへ ZIP内の index.html / sw.js / manifest.webmanifest / アイコンを同じファイル名でアップロードして更新。
3. iPhoneのホーム画面から起動。旧版が残る場合、Safariから公開URLを開いて更新後にPWAを再起動する。アプリを削除したりサイトデータを消さない。
4. 新しい「監査」から矛盾とDLC候補をチェック。**自動修正なし**。選択するたび確認ダイアログが表示される。
5. 修正後、JSONバックアップを書き出す。

## 判定
- プレイ履歴と未プレイ状態の矛盾は候補として列挙。自動では直さない。
- DLC判定はタイトル文字列ベース。誤検出や見逃しあり。作品を消さず `contentType=addon` を追加する。
- 重複候補は編集・照合のみで自動統合しない。
- 既存JSON `version:1` のまま互換を維持。既存データの `contentType` が無い場合はゲーム本編扱い。
- 監査の判断にはゲーム購入・実績の外部検証は含まれない。
