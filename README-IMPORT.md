# GAME VAULT 1.2: TrueAchievements無料会員向け一括取り込み

1. 先にGAME VAULTでJSONバックアップを保存。
2. WindowsのChrome/EdgeでTrueAchievementsにログイン。
3. My Games（実績のあるプレイ済みゲーム）の一覧を開き、表示形式をList/Tableにしてゲーム一覧の表を選択しCtrl+C（ページ全体のコピーより表だけのコピーがおすすめ）。
4. GAME VAULT → 一括取り込み →「過去に遊んだゲーム」、取り込み形式「自動判定」→ 貼り付けCtrl+V → 「登録前に確認」。
5. プレビューにゲーム名以外が混入していないことを見て、登録。
6. 次にTrueAchievements → My Xbox Store Library（無料会員は原則直近1年間の購入履歴）→ 作品タイトルの載る表をコピー。
7. GAME VAULT → 一括取り込み →「購入済みゲーム」→貼り付け→プレビュー→登録。過去に遊んだ同名作品は統合される。
8. My Xbox Store Libraryが未設定なら、TrueAchievementsで必要なXbox基本データ連携を認証。My Game CollectionのOwned一覧を用いる場合、その所有ステータスが適切か確認。

注意: 無料会員の購入履歴スキャンには範囲制限があります。サイトのUIによってコピーできる形式が違うため、すべての画面の取り込みを保証するものではありません。プレビューが汚れている場合は登録せず、ゲームタイトル列だけ選択してコピーしてください。iPhoneでは大量の表の選択が難しいためPCでの初期登録を推奨。PCとiPhone間のデータ移行はJSONバックアップ・復元を使用。
