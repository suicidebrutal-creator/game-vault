THE COLLECTION / 02

GAME LIBRARY

購入済みとプレイ済みは別属性。同じ作品はひとつに統合。

QUICK IMPORT

大量のゲームをコピー＆貼り付けで一括登録。ExcelのCSVも読み込める。

① 取り込む一覧の種類

2回に分けて「購入済み」と「プレイ済み」を取り込むと、同じゲームは自動統合されるよ。購入済み・プレイ済みの両方を正確に管理できる。

TrueAchievementsの「My Games」または「My Game Collection」をPCブラウザで開き、表を選択してコピー → この入力欄に貼り付け。「ゲームタイトルのリンク」を含むコピーなら、タイトルを自動抽出するよ。アカウント情報は不要。購入履歴とプレイ履歴は別々に取り込んでね。

② ゲーム名をまとめて貼り付け

CSVはタイトル列を判定。コピーした表は「自動判定」で試してね。抽出内容が違う場合、登録せず一覧を確認。

③ 確認して一括登録

DISCOVERY ENGINE

その日の気分と作品の特徴から、所有ゲームを発掘。

発掘条件

好みのスコアは編集した作品属性から算出。初期は未評価なので、まず気になるゲームの「編集」で特徴を付けてね。評価がない作品も候補から除外せず「評価不足」と表示する。

発掘結果

GAME RADAR

発売日・大型更新・Game Passの動向を、気になる作品ごとに追跡。

ウォッチリスト

公開情報を探す

1.0では情報の自動監視・通知はまだ行わず、公式Xbox情報への検索リンクを提供する。検索先の内容と日付は外部サイトで確認してね。

LIBRARY / QUALITY CONTROL

LIBRARY AUDIT

自動で書き換えず、登録内容の矛盾とDLC候補を確認。作品は削除しません。

監査の使い方

「プレイ履歴あり」と「未プレイ」は同時に成立しない可能性があります。ただし購入履歴の取り込み時に未プレイが自動設定されたこともあるため、確認してから修正してね。作品種別「追加コンテンツ」は本編数・積みゲー数の集計から除きます。

バックアップ

全ゲーム情報・評価・ウォッチリストをJSONで保存。iPhoneへの引き継ぎにも使える。

登録データ

デモ用の作品は「サンプル」表示付き。デモは自動登録しない。

プライバシーと制約

登録ゲームと分析結果はこの端末のブラウザ内に保存します。ログイン不要。Xboxアカウントとは直接接続せず、購入証明や実績の自動検証もしません。RADARの自動通知と外部ゲームDBからの自動補完はこの1.0に含まれません。端末のブラウザデータを消すと記録も消える可能性があるため、JSONバックアップを定期的に保存してください。
